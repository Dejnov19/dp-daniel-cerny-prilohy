# Elektronické přílohy

Tato složka obsahuje elektronické přílohy diplomové práce. Přílohy jsou rozděleny na tabulkové soubory a zdrojové kódy vytvořených nástrojů.

## Seznam příloh

| Příloha | Soubor / složka | Popis |
| --- | --- | --- |
| FMEA procesu zpracování grafik | `FMEA_proces_zpracovani_grafik.xlsx` | Tabulka FMEA použitá pro analýzu rizik procesu zpracování grafik. |
| Mapování problémů na řešení | `mapovani_problemu_na_reseni.xlsx` | Přehled identifikovaných problémů a navržených nebo realizovaných řešení. |
| Přehled vytvořených nástrojů | `prehled_vytvorenych_nastroju.xlsx` | Souhrn nástrojů vytvořených v praktické části diplomové práce. |
| Časový přehled projektů | `projekty_cas.xlsx` | Orientační přehled času věnovaného jednotlivým projektům. |
| Zdrojové kódy | `projects/` | Zdrojové kódy a podpůrné soubory vytvořených automatizačních nástrojů. |

## Poznámka ke zdrojovým kódům

Zdrojové kódy jsou dále popsané ve složce `projects/`. Každý projekt má vlastní `README.md` se sjednocenou strukturou, popisem účelu, použitých technologií, obsahu složky, typického použití a omezení.
