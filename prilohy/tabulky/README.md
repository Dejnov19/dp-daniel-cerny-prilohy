# Tabulkové přílohy

Tato složka obsahuje tabulkové přílohy diplomové práce ve formátu `.xlsx`. Soubory slouží jako podklad pro analytickou, implementační a ekonomickou část práce.

## Přehled souborů

| Soubor | Příloha v práci | Popis |
| --- | --- | --- |
| `FMEA_proces_zpracovani_grafik.xlsx` | Příloha A | FMEA analýza procesu zpracování grafických podkladů pro výrobu transferů. Soubor zachycuje riziková místa procesu, jejich příčiny, dopady a priority podle hodnot RPN. |
| `mapovani_problemu_na_reseni.xlsx` | Příloha B | Mapování identifikovaných problémů na navržená nebo realizovaná automatizační řešení. Tabulka propojuje slabá místa workflow s konkrétními nástroji a jejich přínosy. |
| `prehled_vytvorenych_nastroju.xlsx` | Příloha C | Souhrnný přehled vytvořených nástrojů, jejich prostředí, hlavních funkcí, vstupů, výstupů a aktuálního stavu použití. |
| `projekty_cas.xlsx` | Příloha D | Orientační časové podklady k jednotlivým nástrojům a výpočty úspor dosažených jejich zavedením. Soubor slouží jako podklad pro ekonomické zhodnocení. |

## Poznámka k použití

Soubory jsou určeny primárně jako přílohy k diplomové práci. Jejich účelem není nahrazovat text práce, ale doložit podrobnější tabulkové podklady, na které se práce odkazuje v analytické, implementační a hodnoticí části.
